# Stickman Fight

Online 1v1 Stickman fighting game.

## Features

- Online multiplayer
- Room codes
- Player 1 / Player 2
- Server-side game simulation
- Real-time WebSockets
- Mobile controls
- PC keyboard controls
- Punch
- Kick
- Block
- Jump
- Knockback
- Hit stun
- Fire Fist
- Lightning Dash
- Wind Slash
- Ability cooldowns
- Health bars
- 90 second rounds
- KO
- Draw
- Rematch
- Animated stickmen
- Particles
- Canvas rendering
- Responsive UI
